## Purpose

从 NX Studio 的参考导出确定基准配方的渲染变换，使渲染结果以尼康自身为基准，而不是用第三方近似凑合。

## ADDED Requirements

### Requirement: 参考导出的采集与校验

系统 SHALL 定义参考导出的采集清单，并在使用前校验其满足标定前提。不满足前提的参考数据 MUST 被拒绝，而非降低权重后继续使用。

#### Scenario: 前提条件

- **WHEN** 采集参考导出
- **THEN** 每张导出必须满足：ADL 关闭；Picture Control 为指定的基准；无其他调整；由 NX Studio 从与配对 NEF 相同的原始文件导出

#### Scenario: 校验失败

- **WHEN** 某张参考导出未关闭 ADL 或含有额外调整
- **THEN** 该条被明确报告为不合格并排除，且报告不合格的原因

#### Scenario: 配对完整性

- **WHEN** 清单中的某个 NEF 缺少对应的参考导出
- **THEN** 报告缺失，且不静默跳过

### Requirement: 尊重参考导出的色彩空间

系统 SHALL 依据参考导出中内嵌的 ICC 配置文件，把参考像素转换到线性空间后再参与拟合。系统 MUST NOT 假定参考导出位于 sRGB。

#### Scenario: 内嵌 ICC

- **WHEN** 参考导出内嵌了某个 ICC 配置文件
- **THEN** 拟合前按其转换到线性，且报告实际使用的配置文件

#### Scenario: 缺少 ICC

- **WHEN** 参考导出没有内嵌 ICC
- **THEN** 明确报告该情况并按约定的默认空间处理，同时在结果中标注这一假定

### Requirement: 拟合基准变换

系统 SHALL 从「线性 RGB 输入」与「参考输出」的配对中拟合出基准变换，并把结果保存为可复用的数据。

#### Scenario: 产出可复用数据

- **WHEN** 拟合完成
- **THEN** 产出包含变换数据的文件，供渲染阶段直接加载，无需重新拟合

#### Scenario: 数据可追溯

- **WHEN** 查看拟合产出的数据
- **THEN** 其中记录了所使用的参考文件清单、基准名与配方编码

#### Scenario: 拟合是离线的

- **WHEN** 日常渲染
- **THEN** 渲染过程 MUST NOT 依赖参考导出文件的存在，只依赖拟合产出的数据

### Requirement: 报告拟合质量

系统 SHALL 报告拟合质量，至少包含 ΔE00 的中位数与 P95 分位。

#### Scenario: 达到目标

- **WHEN** ΔE00 中位数 ≤ 1.0 且 P95 ≤ 3.0
- **THEN** 报告为达标，并给出统计摘要

#### Scenario: 未达目标

- **WHEN** 任一指标超出目标
- **THEN** 明确报告为未达标并给出实际数值，MUST NOT 静默接受或只报告平均值

#### Scenario: 逐样本可查

- **WHEN** 总体达标但个别样本误差很大
- **THEN** 报告误差最大的若干样本，便于判断是拟合问题还是参考数据问题

### Requirement: 基准数据可替换

系统 SHALL 允许替换基准变换数据而不修改渲染代码。

#### Scenario: 更换标定

- **WHEN** 提供了另一份基准变换数据
- **THEN** 渲染使用新数据，代码无需改动

#### Scenario: 多份基准共存

- **WHEN** 本机同时存在多个基准（如 NEUTRAL 与 FLEXIBLE COLOR）的变换数据
- **THEN** 渲染按配方身份中的基准编码选择对应的一份
