## 2. RAW 解码（capability `render/raw-decode`）

- [ ] 2.1 取出标定元数据：白平衡系数、两个光源的相机色彩矩阵、白电平、黑电平、CFA 排布、裁切区；验证 Z8 的 NEF 上白平衡与尺寸同 LibRaw 一致（`[1.8125, 1.0, 1.5703]`、8280×5520、裁切区 8256×5504 @(12,8)）
- [ ] 2.2 实现黑电平扣除与白平衡，验证输出不含任何 gamma 或色调曲线——用一组线性递增的输入值确认输出仍线性
- [ ] 2.3 实现去马赛克，验证在 45 MP 的 NEF 上输出 `8256×5504` 的线性 RGB，并在代码中标注算法来源及其许可

- [ ] 2.5 实现不支持机型的明确失败：用一个改写了机型标识的 NEF 验证返回指明机型与原因的失败，而非产出图像

## 4. 渲染（capability `picture-control/render`）

- [ ] 4.1 实现 257 级曲线的施加，验证已知输入的映射结果；并验证**非单调曲线被原样施加**（构造一条非单调曲线，确认不被拒绝也不被单调化）
- [ ] 4.2 实现 8 段色相混合器（R,O,Y,G,C,B,P,M）；验证只调整某一段时其余段基本不受影响，以及全中性时输出与未施加时一致
- [ ] 4.3 实现三区校色及其 blending / balance；验证三区分别生效，以及全中性时输出与未施加时一致
- [ ] 4.4 实现标量施加；验证哨兵值被识别为「不适用」并跳过，**不得当作 −127 施加**（构造哨兵与非哨兵两组输入对比）
- [ ] 4.5 实现「先基准、后配方」的顺序，并按基准**编码**而非名称字符串选择基准变换；验证两个名称不同但编码相同的配方选中同一份基准
- [ ] 4.6 验证渲染是纯函数：同一输入渲染两次逐位相同，且输入缓冲未被改动

## 5. 标定（capability `picture-control/calibration`）

- [ ] 5.1 实现参考导出清单与校验工具：检查每张导出满足「ADL 关闭、PC 为指定基准、无其他调整、与配对 NEF 同源」，不满足者报告原因并排除；验证对故意构造的不合格样本能正确拒绝
- [ ] 5.2 **【需要你手工执行】** 按清单用 NX Studio 从 `simple/` 的 NEF 及若干张行程照片重导参考样张（PC=NEUTRAL、ADL 关闭、无其他调整）；验证清单中每条都有对应文件，缺失者被报告
- [ ] 5.3 实现按参考导出内嵌 ICC 转换到线性；验证使用 `Nikon sRGB 4.0.0.3002` 时结果与当成 sRGB 处理**不同**（锁死"必须尊重 ICC"这条），并在缺少 ICC 时明确报告与标注假定
- [ ] 5.4 实现拟合：由（线性 RGB, 参考输出）配对拟合出「一维色调曲线 + 三维色彩查找表」，产出可复用数据文件

- [ ] 5.6 把样本划分为拟合集与验证集，验证报告中区分两者的 ΔE，避免过拟合被掩盖
