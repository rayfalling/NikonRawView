## 4. 渲染（capability `picture-control/render`）

- [x] 4.1 实现 257 级曲线的施加；已验证端点保持、中间线性插值、超出定义域按端点延拓不裁切，以及**非单调曲线被原样施加**（构造先上后下的曲线，确认未被拒绝也未被单调化）
- [x] 4.2 实现 8 段色相混合器（R,O,Y,G,C,B,P,M）；已验证各段权重在色相环上处处和为 1（保证全中性即恒等）、段中心权重为 1、只调红段时青色基本不受影响
- [x] 4.3 实现三区校色及其 blending / balance；已验证三区权重处处和为 1（保证全中性即恒等）、只设暗部时暗部被抬升而亮部几乎不动
- [x] 4.4 实现标量施加；已验证哨兵被识别为「不适用」并归零，且**反例成立**——若把 −127 当数值施加会产生明显偏移（这正是要避免的）；对比度以 0.5 为轴、饱和度拉到最低应变灰
- [ ] 4.5 实现「先基准、后配方」的顺序，并按基准**编码**而非名称字符串选择基准变换；验证两个名称不同但编码相同的配方选中同一份基准
- [x] 4.6 验证渲染是纯函数：已验证同一输入渲染两次逐位相同、输入缓冲未被改动，且处理顺序固定并对外报告（`curve → hue-blender → color-grading → scalars`）
