## 4. NP3 / NCP 容器（capability `picture-control/np3`）

- [x] 4.1 实现 chunk 遍历框架：自 `0x10` 起按 `[u32BE tag][u32BE len][payload]` 前进，**结束符为单个 u32=0**；未识别 tag 的原始载荷被保留，验证遍历在四份注册表配方上均正常终止
- [x] 4.2 实现名称（`0x0200`）与 base 编码（`0x0300`）解析，验证四份注册表配方的名称与 base 编码符合期望（`0x00C3`、`0x03C2`、`0x03C2`、`0x0020`）
- [x] 4.3 实现 `0310` 代标量、色相混合器（`0x1F00`，恰好 8 段，顺序 R,O,Y,G,C,B,P,M）与校色（`0x2000`）解析，验证 `MSLT-XTRA400-V0.5` 解析出 8 段混合器
- [x] 4.4 实现曲线块解析（`tag=0x00000002`，`len=578`）：读出控制点数量与 257 级 u16BE LUT，验证在 `MSLT-XTRA400-V0.5` 与边车 `LINKS-Nature` 上均得到 5 个控制点且 LUT 单调
- [x] 4.5 实现 `0300` 代解析（曲线块 LUT 位于载荷 +62 而非 +64），验证三份 `0300` 配方均解析成功
- [x] 4.6 编写**固定偏移反例测试**：断言以固定偏移硬读曲线 LUT 在偏移不同代次上无法通过接受条件——把"禁止固定偏移"变成可执行断言而非注释
- [x] 4.7 实现配方等价性判定（按名称与参数），验证注册表的 `0300` 版与边车的 `0310` 版 `LINKS-Nature` 被判为同名，且各自报告代次与参数差异
- [x] 4.8 实现"非配方容器"的显式返回，用随意二进制文件验证不 panic
