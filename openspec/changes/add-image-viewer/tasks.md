## 2. 预览抽取（capability `view/preview`）

- [ ] 2.1 实现内嵌预览的发现：走 IFD/SubIFD 链找出全部预览档（`JPEGOffset` / `JPEGLength`），复用 `src/tiff.rs`；验证在 `DSC_4143.NEF` 上列出四档且尺寸与字节数与实测一致（`640×424`、`160×120`、`1620×1080`、`8256×5504`）
- [ ] 2.2 实现**只读文件前部**的抽取：验证抽取过程中读入的字节数远小于文件总大小（样本 NEF 为 51.9 MB）
- [ ] 2.3 实现按用途选档：网格取最小档、单张取不小于显示区域的最小档；验证两种用途下选出的档位不同
- [ ] 2.4 实现 JPEG 文件的直接使用路径：验证 JPEG 不做多余抽取
- [ ] 2.5 实现降级：构造一个无内嵌预览的文件与一个预览字节损坏的文件，验证前者显示明确占位提示、后者报告该档不可用并尝试其余档，均不崩溃
- [ ] 2.6 测量并记录性能基准：对同一批 NEF 分别测预览抽取与完整解码的中位耗时，验证预览抽取显著更快，并把数值写入仓库
