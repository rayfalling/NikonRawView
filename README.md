# NikonRawView

解决两件事：**尼康工坊（NX Studio）看图太慢**，以及 **Lightroom Classic 无法解析尼康云创（Nikon Imaging Cloud）色彩**。

核心思路：用同一张照片的 **RAW 与机内 JPEG 配对**，反推出两者之间正确的颜色映射。

> 项目刚初始化，目前只有这份说明与 `.gitignore`，代码结构待定。下文「计划中的流程」是设计意图，**尚未实现**。

---

## 问题

### 1. 尼康工坊看图慢

尼康工坊（NX Studio）在浏览、筛选大量 NEF 时响应很慢，逐张打开确认对焦与构图的开销尤其明显，不适合作为快速看图/初筛工具。

### 2. Lightroom Classic 无法解析尼康云创色彩

尼康云创（Nikon Imaging Cloud）把「色彩方案 / Imaging Recipe」下发到相机，拍摄时由相机 ISP 把该风格**烘焙进机内 JPEG**。而 NEF 记录的是传感器原始数据加一部分厂商 MakerNote：

- 机内 JPEG 里看到的是**已应用云创色彩**的结果；
- Lightroom Classic 不识别云创相关的厂商标签，只会用自己那套相机配置文件去解释 RAW，
- 结果就是**云创的色彩在 LrC 里丢失或明显偏色**，NEF 与机内 JPEG 观感对不上。

## 思路

同一场景、同一次拍摄通常同时存在 NEF 与机内 JPEG，这天然构成一组监督样本：

| | 含义 |
|---|---|
| 机内 JPEG | RAW 经相机 ISP + 云创色彩方案处理后的结果，即我们想要复现的「正确外观」 |
| NEF | 未经处理的原始数据，保留最大调整空间 |

把两者配对，就得到大量 `RAW 值 → 目标色` 的对应关系，可以求解一个映射 `f`，使 `f(RAW) ≈ 机内 JPEG`，从而把云创外观搬到任意 RAW 处理流程中（LrC 相机配置文件 / DCP / 3D LUT / 自建快速看图器）。

## 计划中的流程

1. **采集** —— 固定机位与曝光拍摄 NEF + 机内 JPEG（云创方案已应用）；样本建议同时覆盖色卡与自然场景。
2. **配对与对齐** —— 处理 JPEG 相对 RAW 的裁剪、缩放、镜头校正差异，保证像素级对应。
3. **采样** —— 在色卡色块与自然场景上取对应点，构建训练样本。
4. **求解** —— 拟合映射：最小二乘 / 多项式 / 3D LUT，或在相机配置文件层面拟合参数。
5. **评估** —— 用 ΔE 等指标量化误差，并做可视化对比。
6. **导出** —— 生成 LrC 可用的相机配置文件 / 预设 / LUT。
